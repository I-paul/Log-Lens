# LogLens

Architecture Diagram:
![alt text](image.png)


Monorepo containing the LogLens components:
- **[extension/](file:///d:/LogLens/extension)**: Chrome extension (Manifest V3) for user-facing log interaction and display.
- **[middleware/](file:///d:/LogLens/middleware)**: Node.js + Express backend service written in TypeScript for API orchestration and requests.
- **[backend/](file:///d:/LogLens/backend)**: Python FastAPI application for log analysis, processing, and backend service logic.
